About Jumping Rivers

## Issue templates

`.github/ISSUE_TEMPLATE/` holds the default issue templates for every repository in `jumpingrivers`.
They match the GitLab group templates in `jumpingrivers/issue-templates`.

- `problem.md`: something is broken
- `request.md`: a new feature or change

A repository with its own `.github/ISSUE_TEMPLATE/` folder uses that instead.
The default labels (`complexity::`, `effort::`, `priority::`) only apply where the repository has those labels.
GitHub has no organisation-level labels, so they are created in each repository.
